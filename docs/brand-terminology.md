# Pick ブランド用語集

## コアアクション

| 用語 | 読み | 使い方 |
|------|------|--------|
| ピックする | ぴっくする | 「英語フレーズを選び取る」行為。動詞として使用。 |
| ピック | ぴっく | ピックされたフレーズ・コンテンツを指す名詞。 |
| Repick | リピック | 間違えたフレーズを再練習すること。 |

## 文言ルール

### 動詞の表記
- 英語のままの "Pick" は使わない → 平仮名/片仮名「ピック」に統一
- 例: `Pickしたフレーズ` → `ピックしたフレーズ`
- 例: `AIがフレーズをPickします` → `AIがフレーズをピックします`
- 例: `英語をPickする` → `出会いから英語をピックする`

### 「Pick Streak」
- 連続日数 に統一（streak page ヘッダー・ラベルとも）
- 例: `Pick Streak ${N}日` → `${N}日連続`

### 「マイ ピック」
- スペースなしの `マイピックリスト` に統一
- BottomNav など幅が狭い箇所は `マイピック`（リスト省略）

### 「英語をPickする」
- `出会いから英語をピックする` に統一（能動性・体験の強調）
