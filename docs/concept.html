😔 解いている課題

既存の英語学習アプリの問題

  • 教材フレーズは覚えても実務で使えない
  • 自分の仕事・趣味の文脈と完全に乖離している
  • 「会議で使えた」「読めた」実感が得られない
  • インプット体験と学習が完全に分断されている
  • 継続するモチベーションが続かない
VS

Pick のアンサー

  • 自分の議事録・字幕・技術記事がそのまま教材になる
  • AI が「あなたの目的」に合うフレーズを自動でピック
  • チャレンジで即日確認 → 翌日から使える感覚
  • 出会い（インプット）→ ピック → チャレンジが1アプリ完結
  • Pick Streak・チャレンジ記録 でゲーミフィケーション

設計の3原則

① 文脈一致
ユーザーが実際に体験したテキストだけを教材にする。汎用フレーズ集は作らない。
② 能動性
「選び取る主体はユーザー」。AI はピックを提案するが、最終的な学習意図はユーザーにある。
③ 即時性
今日出会ったフレーズを今日チャレンジできる。体験から学習までのラグを最小化。

⚡ 主要機能

📋

ソース追加（ピック）

テキストを貼り付けるだけ。Claude Sonnet が学習目的・レベルに合わせてフレーズを自動抽出。JSON 部分回復機能で大量テキストも安全処理。

🎯

チャレンジ

テキスト入力で回答 → Claude Haiku が correct / almost / repick の3段階で即時採点。「スキップ」ボタンで AI 採点なしの即解説も可能。

💡

AI Coach 解説

不正解・惜しい時に自動表示。「話すとき」「聴くとき」「使い分け」「NG パターン」の4セクション構成。解説は DB キャッシュで再表示高速化。

🔄

ピックアップ チャレンジ

直近5セッションで2回以上不正解のフレーズを優先出題する focus モード。不足時は通常チャレンジに自動フォールバック。

📊

チャレンジ記録 & Pick Streak

14日間チャート・難易度別/シーン別正解率・連続日数カレンダー（過去6ヶ月・正解率別色分け）。

𝕏

X（Twitter）シェア

チャレンジ結果を 1200×630px Canvas PNG で生成・Supabase Storage にアップロード → Twitter Cards 自動表示。Safari の suspend 問題に完全対応。

📱

PWA

iOS Safari「共有→ホーム画面追加」バナー / Android Chrome ネイティブインストール。ホーム画面から直接起動可能。

🎓

オンボーディング

学習目的（2階層）・レベル・英語力チェック（多肢選択）→ プロフィールに合ったシードフレーズを自動挿入。

💳

サブスクリプション

Stripe 連携。Free / Starter(¥500/月) / Pro(¥1,200/月) の3プラン。Checkout・Webhook・Customer Portal を完全実装。
