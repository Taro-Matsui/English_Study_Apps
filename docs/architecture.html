DB スキーマ（主要テーブル）

テーブル主要カラム備考
phrasesuser_id, phrase, translation, explanation, deleted_at, added_date論理削除。.is('deleted_at', null) 必須
quiz_sessionsuser_id, started_atチャレンジセッション単位
quiz_answerssession_id, phrase_id, status, response_time_msstatus: correct / partial / incorrect
import_jobsuser_id, status, source_type, textフレーズ抽出ジョブ
subscriptionsuser_id, stripe_subscription_id, stripe_customer_id, plan, status, current_period_endmigration 015。Webhook 経由で更新
Supabase クライアント使い分け: Route Handler DB 操作 → getSupabaseAdmin()（SERVICE_ROLE） + .eq('user_id', user.id) 必須。 Client Component → createBrowserSupabaseClient()（シングルトン）。 ANON key での Route Handler DB 操作は auth.uid() が null になりデータ 0 件になるため禁止。
